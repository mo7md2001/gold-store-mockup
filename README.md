# Gold Store — Design Mockup

Luxury women's gold jewelry store — interactive design mockup (7 screens: home, product pages, cart, checkout, success).

- Products: 21k gold anklet (5 g / 10 g) and a pure-diamond anklet
- Payment model: cash on delivery + manual InstaPay / bank transfer with WhatsApp receipt
- Arabic RTL, cream & gold luxury theme

Open `index.html` and switch screens with the `?s=` parameter (1–7).
